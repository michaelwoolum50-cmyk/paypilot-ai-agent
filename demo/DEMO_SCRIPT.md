# PayPilot — Demo Video Script (under 3:00)

**Setup:** app running at localhost:5000, PayPal sandbox creds exported,
"Preview only" UNCHECKED for the live-order shot. Screen-record at 1080p.

---

**[0:00–0:20] Hook**
> "What if you never had to shop again? Meet PayPilot — an AI agent that finds
> your deal and pays with PayPal. Watch."

Show the landing page. Type "Sony WH-1000XM5 headphones", budget $300.

**[0:20–1:10] Shop once — the agent thinks out loud**
Click "Let the agent shop". Scroll the reasoning trace as it fills:
> "The agent found three listings. The $328 Sony is over budget — rejected.
> The open-box at $279 scores 57. The Bose at $299 wins with 72 — new
> condition, 4.7-star seller, fast shipping. Every line of its thinking is
> right here."

**[1:10–1:50] PayPal order — real sandbox money movement**
> "And here's the agentic commerce part — the agent just created a real PayPal
> order in the sandbox."

Click the approval link → PayPal sandbox checkout page loads (show the order
summary). Narrate: "Buyer approves, PayPal captures, deal done. The agent did
the shopping; you just say yes."

**[1:50–2:30] Autopilot watch**
Switch to Autopilot: "Kindle Paperwhite", buy under $110, cap $150.
> "Now it watches. Thirty-day price history — the used unit dipped to $87 last
> week, under target. Agent executes within the hard cap. You set the rules;
> it never spends a cent over."

**[2:30–2:55] Close**
> "PayPilot: PayPal Orders API plus an AI that shops like you would —
> transparently. Built for the PayPal AI Hackathon. Code's on GitHub, MIT
> licensed. Never shop again."

**End card:** GitHub URL + "PayPal sandbox — no real money moved."
